# Public release gates

- [ ] Document software license, dependencies and third-party attribution.
- [ ] Pass controlled, reviewed public-source import (no customer financial records or secrets).
- [ ] Passing CI for supported Frappe/ERPNext versions and optional integration combinations.
- [ ] Install/upgrade/migrate/rollback confirmed on clean QA.
- [ ] Company permission isolation tests and negative authorization tests.
- [ ] All ZATCA rules referenced with effective dates, verification state and synthetic acceptance tests.
- [ ] Full source-line reconciliation for each supported return box.
- [ ] No hard-coded client company/account numbers, tax ID or tax periods.
- [ ] Arabic/English print and export parity.
- [ ] Documented manual filing, no claim of ZATCA endorsement/certification.
- [ ] Independent functional security and accounting review.
- [ ] Release notes, support policy and explicitly unsupported cases.
