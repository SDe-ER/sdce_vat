# Compatibility matrix

All entries below are **targets**, not confirmed release support.

| Component | Target | Status |
|---|---|---|
| Frappe Framework | v16.x | To test |
| ERPNext | v16.x | To test |
| Python / Node / MariaDB / Redis | Versions supported by the selected Frappe v16 release | To pin/test |
| ksa_compliance | Optional, version-tested integration | To test with and without |
| HRMS | Optional Expense Claim adapter | To test with and without |
| Language | Arabic (RTL), English | To test |
| Currency | SAR baseline; mixed-currency transactions with ERPNext exchange rates | To test |
| Operating model | Multi-company / separate VAT registrations / separate periods | To test |
| Other ERPNext versions | Not claimed | Unsupported until tested |

Only confirmed versions from CI plus real isolated QA validation belong in a published support matrix.
